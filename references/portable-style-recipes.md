# 无图也可使用的视觉配方

这些是原创设计起点，不是图片复刻保证。依据来自已核对的发布规范、既有 STYLE 文字卡及设计实验记录。没有查看当前图片时明确说明仅按文字工作；用户描述优先，不要求所有用途从本表选。

## 先描述关系，再写色值

将所选方向写成六个关系：

1. **焦点**：主标题、内容主体和主操作谁先被看到，比例差多大。
2. **构图**：对称/非对称、主从区域、边缘裁切与视线移动。
3. **层次**：背景→大字/色块→主体→遮挡→可读信息；只有需要的层才保留。
4. **字形**：标题与控件/正文的分工，字号反差、字重、编号和基线。
5. **几何与材质**：直角/圆角/斜切是否有职责，平涂/纸感/立体主体如何配合。
6. **交互与密度**：选中、悬停、焦点、禁用、长文本和小屏如何延续语言；装饰不能冒充状态。

UI 转译先确定真实任务和信息层级，再应用这些关系；不要把海报所有装饰直接放进阅读区。作品内容类型与产品身份分别判断。

## 黄黑工业标识

依据：原库 STYLE-001，已审阅代表样本的文字卡，置信度中；原始归档图通过 [来源索引](style-preview-gallery.md) 定位，不使用生成UI当参考。卡片建议色约 `#FFE72E` / `#242424` / `#F0F0E7`，不是从每张图测出的精确值。

视觉关系：黄黑大面积强对比建立分区；纵向栏或左右信息板、斜切遮挡与圆形节点形成节奏。粗重窄体标题对比小编号；线、网格和点阵从属于信息，不能让所有区域同样抢眼。基础可用平涂，机械立体主体只是可选表现，不是此风格的必要条件。

UI 转译：流程/入口可形成分栏，当前入口用面积、位置或反差突出；主操作与次级标签保持区别。正文页降低黄面占比和背景噪声。不能从示例推导必须六栏、必须有机器、所有按钮都斜切；避免警戒条泛滥和照搬现有阵营标志。

## 珊瑚薄荷活力拼贴

依据：原库 STYLE-010，已审阅代表样本的文字卡，置信度中；原始归档图通过 [来源索引](style-preview-gallery.md) 定位。建议色约 `#F289A2` / `#54D9CA` / `#FFF1DD`。

视觉关系：奶油底承载轻色块，珊瑚标题与薄荷反衬建立活力；倾斜标题形状、纸张/贴纸和少量星形围绕主视觉，而非占满功能区。厚重标题与轻量辅助信息分工，前后纸面交叠形成层次。

UI 转译：导航、主操作和选中态共享强调色与纸面边界；插画集中于入口或展示区，给文字与操作留安静区域。不从曾生成的概念图推导必须浮岛或空间工作台；不复制原作人物，也不将插画密度搬进编辑器。

## 强风格化游戏终端（探索文字方向）

依据：2026-10-14 风格化终端实验提示词与历史讨论。它只是文字探索建议，没有原始参考时不可当作有来源的风格示例，不是明日方舟官方规范或用户已接受的岚笺产品方案。

视觉关系：黑/白大块分区搭配克制的橙色焦点；大标题、序号、硬边切口与不对称构图产生冲击。主体跨越区域边界，信息板遮挡主体一部分形成前后关系；小标签服务分类与导航，功能文字始终可读。比起增加装饰，更重视主从面积、裁切与焦点反差。

UI 转译：将真实任务作为视觉焦点，其他入口退为次级；每个区域有明确职责。不要凭提示词造不存在的产品功能、伪装状态或复制游戏图标。需要精确套用岚笺发布版时应选择上方固定预设。

## 组装成可执行的设计提示

按顺序描述：用途与准确内容→选定方向的构图/排印关系→主要色板与材质→焦点和操作层级→尺寸/可读性→必须保留与避免。完整参考图需包含所需文案与功能标签，不能继承旧卡片中“文字全部后期添加”的冲突片段。

已有图不可访问仍可据此原创；需要精确编辑或复刻目标时，先补齐必要目标图。不要从未看到的图片臆造字体名称、材质细节或真实图层。
