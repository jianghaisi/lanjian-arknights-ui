# 发布版本的设计语言与令牌

以下数值是固定公开提交的实现基线，供复现或适配；不是从旧 MASTER 恢复的通用设计标准。已有项目中沿用其语义令牌，不用这些数值覆盖作者设置。

## 配色分工

| 语义 | 清昼默认 | 墨夜 | 宣纸差异 |
| --- | --- | --- | --- |
| 画布 `--color-paper` | `#F3F0E8` | `#202522` | `#EDE7DB` |
| 内容面 `--color-surface` | `#FAF9F5` | `#282E2A` | `#F9F5EB` |
| 文字 `--color-ink` | `#1D2220` | `#EEEFE7` | 沿默认 |
| 次要文字 `--color-muted` | `#676E69` | `#B0B8B1` | `#5F665F` |
| 分隔 `--color-line` | `#D8D6CF` | `#49534B` | `#D3C9B9` |
| 玉绿 `--color-jade` | `#287A68` | `#83C4AE` | 沿默认 |
| 过程信号 `--color-orange` | `#E99A35` | `#E9AB59` | 沿默认 |
| 失败 `--color-danger` | `#B4473E` | `#E7978C` | 沿默认 |
| 次层背景 `--color-rail` | `#E5E5DF` | `#303832` | `#E4DED1` |

主要表单动作另有一对：`--color-action: #EFA348`、`--color-action-ink: #202722`，hover 为 `#F5B86A`。这对前景/背景在各主题保持配对，不把按钮文字改成泛用白色。

深色档案身份面是局部材质：工作区 `--folio-dark: #263B32`，前景 `#F5F3EB`，次级文字 `#C0CEBF`，边线 `#526C5C`。书库主档案有自己的近墨绿 `#202824`。它们是不同组件的合法层级，不要合并成一个全站背景。

玉绿用于选择、导航、链接及状态强调；暖橙用于重要入口、动作或过程信号；失败红对应实际风险。状态还要有文字/形态。编辑器紧凑保存按钮保留其已有深墨动作样式，不把所有 primary 控件机械涂橙。

## 当前样式的所有权

发布版同时存在基础 `desktop.css` 变量与叙事令牌。实际工作台根 `.narrative-terminal` 在 `narrative-terminal.css` 中把 `--canvas/--surface/--ink/--jade` 映射到 `--color-*`；不能从较早加载的根值推断最终颜色。

`app/main.js` 的样式顺序包含基础样式、`narrative-terminal.css`、`approved-archive.css`、`archive-workspace.css` 和交互动效；助笔还有自身样式。修改对应所有者，检查计算样式；不要靠新增全局 `!important` 抹平局部职责。

## 中文排版

| 角色 | 本版本分工 | 尺度参考 |
| --- | --- | --- |
| 书名、内容标题 | `var(--serif)`；LanjianSerif/思源宋体/Noto Serif SC/宋体回退 | 普通 page28、section20、card18 px |
| 控件、标签、数据 | `var(--sans)`；LanjianSans/思源黑体/Noto Sans SC/微软雅黑回退 | control14、body14 px |
| 说明、状态 | 同一 sans | meta12 px；caption11 px 为从属微标签 |
| 正文 | 原编辑器与作者字体/字号/行高偏好 | reading18px 仅默认令牌，不能固定覆盖偏好 |
| 展示标题 | 独立展示角色，非每页套用 | `clamp(28px, 3vw, 40px)`；书库自身标题由专属样式控制 |
| 助笔文档 | 紧凑 sans，独立于页面/正文尺度 | 当前文档12.5px/1.7、内部标题13px/1.6、表格12px |

英文 overline、档案号和时钟是辅助层：可以使用紧凑数字与适度字距，中文功能名仍是第一识别信息。长段中文不加夸张字距，不通过换窄字体掩盖布局不足。

发布源的 LanjianSans/LanjianSerif 是本地字体别名，声明字重范围100–900。复用字体角色，不假定字体已经随技能打包，也不引入运行时远程字体依赖。

## 间距和控件

- 同组控件间距8px，字段间距16px，分区间距24px。
- 页面 gutter 使用 `clamp(16px, 2vw, 32px)`；面板 gutter16px。
- 普通控件高度38px，compact32px，UI 字号14px。其他已验证专属控件保留自己的尺寸。
- 字段采用「标签—输入—帮助/错误」结构。输入本身对齐，不让长说明决定同排控件的基线。单位紧贴数值字段。
- 表单的错误就近显示，保留输入；收起说明不隐藏需要作者处理的问题。

同版本的 `--space-1…5` 从 `.5rem` 起步，是现有命名；不要假定它与另一套4px整数阶梯含义相同。使用语义间距，避免新造平行令牌。

## 几何与细节

| 区域 | 几何规则 |
| --- | --- |
| 普通工作区矩形表单、面板、动作 | 局部 radius0；薄边框，少阴影 |
| 书库主档案和大型入口 | 有限的非对称切角、内框、细网格、边缘标记；切角不裁掉文字和焦点 |
| 助笔/群聊 | 保留其独立圆角语言；助笔面板16px边角、引导面16px、输入12px、部分控件9–10px是局部实现例子 |
| 头像、状态点、单选控件 | 遵循本来形状，不套方角规则 |
| 纸面正文 | 稳定平面；原有行线/版式受作者设置控制 |

网格用低对比细线：工具画布28px栅格，档案内可有自己的较疏网格。定位十字、微标签和橙色斜纹依附真实分区/边界，点到为止，不均匀撒满内容。

沿目标项目现有矢量图标体系保持描边、尺寸和对齐一致；岚笺复用 `StudioIcon` 与现有组件图标。不要以 emoji、新商标或混杂图标库代替其识别语言。
