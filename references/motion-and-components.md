# 组件动画：原始参考与参数实验

风格包括静态视觉与交互节奏。选方向使用原始录屏/动图；自写预览只检验后续参数，不当风格来源。AI将方向落实为参数，不让用户逐个决定缓动曲线。已有方向直接沿用，简单请求不用额外问一轮。

原始动态定位见 [来源索引](style-preview-gallery.md) 及其快照。先核对文件真实格式、来源关系、时间段与观察范围；缩略图、帧数和命名不能证明点击反馈或缓动。没有合适的原始动态就明确缺口，动效方案标为建议。不能把战斗机制/主题宣传动图当作所有组件的交互录屏。

## 随技能提供的参数实验页

打开 [motion-preview.html](../assets/motion-preview.html)，可离线双击运行，无外部字体、脚本、图片或网络依赖。它是本技能编写的实验工具，不是原作组件示例。有可用浏览器面板时打开实际预览；只能给链接时明确请用户打开，不能把链接称为已内联播放。使用本机服务时仅绑定回环地址，不公开托管。

同一内容可切换三个**动效示意配方**，避免把配色变化误当运动差异：

| 示例 | 表达 | 参数起点与来源 |
| --- | --- | --- |
| 克制清晰 | 快速颜色反馈、几乎不位移，适合长时间使用 | fast120 / panel180 / drawer180入120出 / entry160ms，位移2px；本次原创对照 |
| 短促终端 | 小幅位移、利落切换、清楚进退场 | fast140 / panel220 / drawer240入140出 / entry180ms，位移6px；时长/幅度参考已冻结岚笺规则，缓动与示例编排为演示 |
| 柔和层叠 | 稍长收束、轻微弹性与依次出现，适合低频展示 | fast180 / panel300 / drawer320入200出 / entry280ms，位移10px；本次原创对照 |

按钮、标签指示器、局部抽屉和分层消息入场都可手动触发；没有自动循环。操作立即改变真实示例状态，动画只呈现结果。“静止对照”仅用于这个预览且不持久化，不向岚笺产品添加新设置。系统低动态偏好优先禁用位移/动画。

这不是发布版运行录像或可直接移植的完整组件库，也不表示三组节奏均已获用户接受。短促终端不完整复制原组件轨迹；精确使用岚笺预设仍读 [冻结页面与动效](presets/lanjian-release/patterns-and-motion.md)。预览验证不能替代产品状态、性能或作者视觉验收。

## 每种效果都说明什么

| 层级 | 应说明/展示 |
| --- | --- |
| 按钮与卡片反馈 | 悬停、键盘焦点、按下、禁用是否可辨；视觉反馈与实际动作分开 |
| 选择与导航 | 指示器/下划线的移动、内容是否立即可用；快速连续切换最终落在正确选择 |
| 面板/抽屉 | 进入和退出各自节奏、关闭途中重开、焦点归还；不能让不可见控件继续可聚焦 |
| 信息入场 | 淡入/小位移/错峰如何建立主次；稳定后停止，重播不重复执行业务动作 |
| 加载与结果 | 依据实际状态，取消/失败可见；有限演示不能伪装真实进度或保存成功 |

用户只要某个组件时直接处理该组件，不强制展示全套，也不把“增加动效”理解为全站开场、声音或持续扫描。阅读/输入区保持稳定，动效不阻断操作或重新挂载编辑器。

实现约定至少说明：触发事件→变化属性→起止状态→时长/缓动/距离→快速反向与取消→低动态稳定状态。优先 transform/opacity 等适合当前组件的属性；若动画改变尺寸，验证布局、内容和滚动行为。优先目标项目已用的机制，不为普通反馈引入新动画库。

## 低动态、打断和验证

- `prefers-reduced-motion` 下直接达到可用稳定状态，保留颜色/边界/文字等反馈；测试时偏好中途变化也能停止当前运动。
- 连续点击和关闭重开从当前状态反向/替换，取消旧动画与迟到回调；不排队播放过时状态。
- 使用真实键盘和鼠标触发，检查焦点、禁用、Escape、关闭后的不可聚焦，以及窄屏内容是否被裁切。
- 区分“文件能打开”“交互与落点通过”“流畅度观测”“用户认可”。截图只验证稳定构图，不证明运动曲线、帧率或产品可用性。

不能实际播放时给出参数和状态序列，并保留待验证说明；不要根据一张参考图推断其真实动画。GIF/视频可辅助观看时序，但不能证明快速反向和键盘行为。
