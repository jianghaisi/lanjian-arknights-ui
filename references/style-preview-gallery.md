# 原始参考：选择风格用什么图

选风格只用可追溯的原始归档参考、忠实缩略图、真实截图或原始动态资料。AI生成图是待评价产出，不充当风格来源；自写组件实验也不能反过来证明原作的设计。

## 当前覆盖与定位

[source-examples.json](source-examples.json) 是2026-10-16资料目录的可移植元信息快照：28张风格卡、47份去重来源，其中15张卡原有状态为“代表样本已审阅”、13张为“低置信候选”。字体和图标也在这28卡中，不能称为28套完整UI。它不包含媒体或安装者本地路径，不证明当前环境可读、网站在线或新一轮审阅完成。

每项保留STYLE ID、已有状态/置信度、整页/辅助语言身份、源ID、原文件SHA和归档公开URL（source_urls）。原始/预览绝对路径、磁盘链和本机可用性不分发；接入用户的库时按源ID/哈希匹配位置。动态资料单列，未完整时序分析的保持待审；字体样张若存在，是原字体的程序排印预览，不是原作者设计海报。

1. 本地库可用时读 [连接规则](local-library.md)，实时查询styles.json和assets.json，按用途选1—3方向；快照提供元信息线索，不替代实时库。
2. 读取所选STYLE在用户库中的真实路径，或在允许范围内查看已记录的原始地址，核对源ID/SHA与预览对应关系，再查看原图；地址失效或没有访问能力时明确说明。长图或小缩略图不足以支持细节结论时说明范围。
3. 推荐每个方向时实际嵌入原图或已有忠实预览，使用当前实际绝对路径；附卡名、来源定位、可迁移关系、一个取舍。来源制作方法未知时不承诺人工或非AI创作。
4. 原文件不可访问时说明缺图，只给文字方向或让用户指定已有参考；不生成替代图，不伪造展示或来源。图库换位置应沿用源ID/哈希对账，不能按相似文件名盲换。

不将原作角色、商标、文字内容或独特布局直接搬成新设计。此索引只保存定位信息，不自动复制、公开打包或上传原始媒体；来源URL是归档记录，不能冒称本轮验证了网站或作者身份。

## 推荐粒度与试用中发现的问题

CLI按关键词匹配，不理解“完整页面方向”与“辅助控件语言”的差别。一次“工业 高对比 UI”查询将单线箭头图标和等距导览列入前三，不能原样当三个整页方向交给用户。

先筛完整构图与排印方向，例如黄黑工业、大留白巨字、象牙白衬线、珊瑚薄荷拼贴；图标/字体作为方向内部的可选配套。是否适合UI须按任务转译，原媒介标签是建议，不是全部场景验证。

## 动态参考与参数实验分开

原始动态资料的归档URL、源ID与SHA在快照的animated_references中，媒体另行从用户库或允许的地址读取。只有实际看过相关时段才描述其时序；单帧、帧数、URL名称不能证明按钮响应、缓动或时长。界面主题展示、战斗机制演示与真正的组件交互录屏分别标注。

已有 [动效实验页](../assets/motion-preview.html) 由本技能编写，只比较拟议参数与交互落点，不作为参考来源。使用与验证范围见 [动效指南](motion-and-components.md)。精确岚笺发布预设仍定位 [固定来源](presets/lanjian-release/provenance.md)，不可用探索稿冒充实机截图。
